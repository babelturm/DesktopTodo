最初只是想让 Microsoft To Do 贴在桌面层，打开工作窗口时自然被覆盖。DesktopTodo 围绕这个需求，做成了一个独立的 Windows 蓝白风格待办小组件。

### 功能

- 桌面层显示，可固定位置和大小。
- 自定义列表分类、步骤、备注、重要标记及截止日期。
- 指定时间和倒计时提醒，使用 Windows 系统通知。
- 已完成任务折叠收纳，右键删除需二次确认。
- 本地保存、自动备份、开机启动和托盘运行。

### 本版修复

- 空白和卡片间距显示普通箭头，仅可点击区域显示手形。
- 滚动、折叠或增删任务后同步刷新光标。
- 统一主列表与详情页的五角星，详情五角星与步骤 ⋮ 竖直对齐。

### 下载与使用

下载下方 `DesktopTodo-v2.0.5.zip`，解压运行 `DesktopTodo.exe`。Windows 10 / 11，无需安装和账号。源码也包含在下载包内。

升级前从旧程序托盘菜单选择“退出”，再运行新版，任务数据保留。提醒需要程序持续运行或留在托盘。此应用使用自己的本地数据，目前没有 Microsoft To Do 同步。
