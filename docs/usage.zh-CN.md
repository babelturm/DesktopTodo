# 桌面待办 2.0.5

双击 `DesktopTodo.exe` 运行，无需安装、账号或管理员权限。升级前请在旧程序托盘菜单选择“退出”，再从新解压的文件夹启动本版。正式任务仍保存在 `%APPDATA%\DesktopTodo`，包内不包含测试任务。

## 本次调整

修正主列表整块区域始终显示手形的问题。现在空白、卡片间距、无滚动条的右侧留白显示普通箭头；任务卡片、完成圆圈、五角星、已完成折叠按钮和可用滚动区域显示手形。滚动、展开、添加、完成或删除导致鼠标下方内容改变时，也会重新判断光标。文字输入框使用文本光标，不可用按钮显示普通箭头。

保留上一版统一后的五角星与步骤竖排 ⋮ 对齐效果。以下为 2.0.3 延续的交互。

- 移除待办、已完成和回收站三个分页。未完成任务在上方，已完成任务收纳在下方的“已完成 · 数量”区域。
- 已完成区域默认折叠，单击即可展开。每个列表分别保存折叠状态，重启后仍然保留。没有已完成任务时不显示折叠按钮。
- 点击已完成任务的圆圈可恢复为待办，回到上方。任务详情、步骤、备注、重要标记和提醒信息均保留。
- 右键任务 → **删除任务**。菜单打开时按 **Delete** 同样进入删除确认。快捷键只在该任务菜单打开时生效，不影响输入框中的 Delete 编辑操作。
- 确认弹窗显示任务名称，红色“删除”按钮执行永久删除；“取消”、Esc 或关闭按钮保留任务。默认焦点和 Enter 操作为取消。
- 确认删除后，任务、步骤和备注从当前清单移除，不进入回收站，也不能通过撤销操作恢复。此前的撤销记录不会让它重新出现。
- 详情页右上角 ⋮ 打开同一任务菜单；移除原来底部的直接删除按钮。
- 未完成任务、已完成任务和折叠标题使用同一双缓冲绘制区域。滚动条在卡片右侧独立留白中；底部添加栏与卡片等宽。

## 旧版数据

旧版回收站里的任务自动保留到各自列表的已完成区，可展开后查看或自行确认删除。升级时不会直接丢弃这些任务。

第一次成功保存前，包含旧回收站任务的原始文件额外备份到 `tasks.json.pre-v2.0.3.bak`，此文件不会被日常保存覆盖。1.x 数据仍会归入“今日待办”，并保留 `tasks.json.pre-v2.bak` 原始备份。数据格式继续使用 Version 2，升级后建议持续使用本版。

## 列表

默认提供“今日待办、本月目标、年度计划”。点击大标题或箭头切换列表；左上角菜单和列表菜单可新建列表，列表菜单可重命名或删除当前列表。

- 列表名称为 1–40 个字符，同名名称会提示。
- 新任务归入当前列表，记住上次打开的列表。
- 右键任务 → 移动到列表；详情页“列表”一栏也可移动。
- 删除列表需要选择其他列表接收其中全部任务，包含已完成任务。至少保留一个列表。
- 新建、重命名、移动和合并删除列表支持撤销。永久删除任务不支持撤销。
- “今日待办”等名称仅用于手动分类，不自动按日期清空或转移。

## 主界面与任务详情

主窗口保持在桌面层。右上角大头针固定位置和大小，再点一次解锁；详情页没有固定按钮。右上角横线隐藏到托盘，双击托盘图标恢复；完全退出请使用菜单“退出”。

底部输入任务后按 Enter 或点 ＋ 添加。左键点击任务文字进入详情，右键只打开任务菜单；左侧圆圈完成任务，右侧星标标记重要。

详情页标题、步骤和备注可以直接编辑，停止输入约 0.7 秒后自动保存，也会在离开输入框或返回时保存。中文输入法组合期间延迟保存。步骤文字按 Enter 保存并结束编辑；只有圆圈切换步骤完成状态。步骤右侧 ⋮ 可删除步骤，步骤删除仍支持撤销。

备注为空时显示淡灰色“添加备注”，点击后直接输入。创建时间显示本机时区的年月日和时分。详情页左上角 ← 返回列表。

## 提醒与设置

“提醒我”支持指定日期时间或倒计时，提供 5、15、30 分钟和 1 小时预设，时长范围为 1 分钟至 30 天。“截止日期”单独保存，不自动触发提醒。

提醒使用 Windows 系统通知。需要程序持续运行或留在托盘；完全退出后不会自动唤醒。倒计时的到期时刻会保存，退出期间到期时，下次启动会补发尚未发送的提醒。已完成和已删除任务不发送提醒；全部列表均参与提醒检查。点击通知会打开对应任务。

左上角三横线 → 设置，包含开机启动开关、发送测试通知和快捷键说明。已经开启的开机启动项会更新为当前 EXE 路径，关闭状态保持关闭。Windows 通知开关和勿扰模式可能影响通知的显示。

编辑和确认弹窗只在打开期间保持置顶，并暂停主清单的桌面层刷新；关闭后恢复桌面层行为。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Enter | 添加任务或步骤；保存已有步骤文字并结束编辑 |
| Ctrl + N | 返回主列表并聚焦新增任务输入框 |
| Ctrl + Z | 撤销操作，不含永久删除任务；输入框内使用系统文本撤销 |
| Esc | 从详情返回；取消确认弹窗 |
| Delete | 任务菜单打开时请求删除，仍需确认 |
| ↑ / ↓ | 列表聚焦时选择任务或已完成折叠标题 |
| Space | 切换所选任务完成状态，或展开/折叠所选已完成标题 |

## 保存、备份与源码

数据本地明文保存，没有云同步、网络请求或遥测。菜单可打开数据目录或导出 JSON 备份。`tasks.json.bak` 为前一次成功保存的自动备份；写入使用临时文件与原子替换，失败时不提交内存状态。损坏原文件会保留，无法恢复时不会用空清单覆盖。

EXE、托盘和 Windows 通知继续使用统一的双色蓝色对勾。ICO 内置 16–256 像素共 9 个尺寸。

完整源码位于 `source`，运行 `source\build.ps1` 可使用 Windows 的 .NET Framework C# 编译器构建，无第三方下载依赖。EXE 未数字签名。

开发检查命令（只使用独立测试数据目录）：

```text
DesktopTodo.exe --self-test <测试输出目录>
DesktopTodo.exe --data-dir <独立数据目录> --diagnostics <诊断JSON> --render-test <渲染输出目录>
```
